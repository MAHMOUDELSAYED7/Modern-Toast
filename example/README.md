# Modern Toast Example

This is an example app demonstrating the usage of the `modern_toast` package.

## Running the Example

1. Navigate to the example directory:
```bash
cd example
```

2. Get dependencies:
```bash
flutter pub get
```

3. Run the app:
```bash
flutter run
```

## Features Demonstrated

- Success, Error, Warning, and Info toast types
- Custom toasts with custom colors and icons
- Long duration toasts (5 seconds)
- Long message handling with text wrapping
- Smooth animations and transitions
