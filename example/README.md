# Modern Toast Example

This is an example app demonstrating the usage of the `modern_toast` package.

## Features Demonstrated

- **Predefined Toast Types**: Success, Error, Warning, and Info toasts
- **Custom Styling**: Custom colors, icons, and text styles
- **Border Radius Customization**: Examples showing different corner radius values
- **Icon Control**: Show/hide icons and custom icon usage
- **Duration Control**: Custom toast display duration
- **Text Styling**: Custom fonts, colors, and formatting

## Running the Example

1. Navigate to the example directory:
```bash
cd example
```

2. Get dependencies:
```bash
flutter pub get
```

3. Run the app:
```bash
flutter run
```

## Key Examples

- **Border Radius**: Try the "Custom Border Radius", "Sharp Corners (0px)", and "Very Rounded (50px)" buttons to see different corner styles
- **Custom Styling**: Use the purple and pink custom toast buttons to see custom colors and icons
- **Text Customization**: Try the "Custom Text Style" button for formatted text
- **Icon Control**: Use "No Icon Toast" to see toasts without icons

## Features Demonstrated

- Success, Error, Warning, and Info toast types
- Custom toasts with custom colors and icons
- Long duration toasts (5 seconds)
- Long message handling with text wrapping
